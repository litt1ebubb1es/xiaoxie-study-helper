# 这里放使用视频

约定两个文件，文件名固定（页面按这个名字找，不放就不显示播放器）：

| 文件 | 要求 |
|---|---|
| `demo.mp4` | H.264 + AAC，`-movflags +faststart`，720p，码率 ≤ 1.2 Mbps |
| `poster.jpg` | 首帧截图，16:9，宽度 1280 左右 |

为什么码率卡这么死：演示服务器上行只有 **1.64 Mbps**，码率超过它就会边播边卡。

转码命令（本机有 ffmpeg）：

```powershell
ffmpeg -i 录屏.mp4 -vf "scale=1280:-2" -c:v libx264 -preset slow -crf 28 `
  -maxrate 1200k -bufsize 2400k -pix_fmt yuv420p -c:a aac -b:a 64k `
  -movflags +faststart webdemo\video\demo.mp4

ffmpeg -y -i webdemo\video\demo.mp4 -frames:v 1 -q:v 4 webdemo\video\poster.jpg
```

放好之后重跑一次导出，`data/demo.json` 里会多出 `video` 字段，页面上的播放器就出现了：

```powershell
.\.venv\Scripts\python.exe tools\export_demo_json.py
```
