# 小蟹学习助手 · 介绍短片（99 秒）

按 `mexicat/pdoom-video` 的做法做的：**画面是时间的纯函数**，同一帧永远渲染成同一张图，
所以抽帧预览和最终导出逐像素一致。风格照 `assets/TREATMENT.md`，配色换成橙色主题。

这一版在图形版面之间插了 **50 秒实机画面**：不是录屏，是把真窗口跑起来、按脚本点，
逐帧 `QWidget.grab()` 存成 1920×1080 PNG，再交给渲染器做推轨、圈重点、加字幕条。

- 成片：`out/小蟹学习助手-介绍.mp4` — 1920×1080 / 60 fps / H.264 High CRF 16 / AAC 256 kbps / 99.0 s
- 联系表：`out/contact-sheet.png`（从成片抽 24 帧）
- 音乐：`assets/happy.mp3` 的 **12.0–111.0 s**（99 s = 198 拍，BPM 120），结尾 1.5 s 淡出
- 实机素材：`work/appseq/`（1620 帧 2560×1421 + `manifest.json` 里的点击表）

## 实机画面是怎么来的

```bash
# 逐帧抓应用：脚本点/拖/打字，每帧 grab 一张 PNG（约 85 秒）
.venv/Scripts/python.exe docs/video/capture_app.py

# 只看每个动作结束时的样子（不写帧，几秒钟）
.venv/Scripts/python.exe docs/video/capture_app.py --probe
```

- 抓图按 2560×1421（本机 2K 屏）存，源像素比成片多 1.33 倍：镜头推到 1.5 倍还是 1:1，推到 1.8 倍才轻微上采样，所以推轨敢做大（这一版实机镜头 1.18 → 1.80，靠平移带节奏）。
- `capture_app.py` 复制 `data/selftest.db` 到 `work/capture.db`，往里面种三道题、两条待答、
  一份讲义条目，**不动真库**。
- 真假边界（片子里能看出来的部分都是真的）：本机算力/模型清单来自 `local_deploy.detect_all()`、
  「已连上。50 个模型可选（229 ms）」来自真实的连通性探测、界面点击与滚动全是真事件；
  只有**生成出来的文字**是桩——问模型的回答和「换一个类比」的重讲稿由脚本按时间线一字一句写进去，
  这样每一帧都可复现，也不依赖网络和额度。
- 脚本的动作表在 `build_steps()` 里，一个动作一行；`note_click()` 把每次点击的窗口坐标记下来，
  视频里的指针就照这张表走（点完停 0.5 s，再缓动滑向下一个点）。
- `--probe` 会在 `PROBE_AT` 那几个时间点存单帧，调版式时先看它，别直接跑全片。

## 改文案 / 改时间

- 图形版面：`vlib/plates.py`，一个版面一个类，全文案都在类里（`ITEMS`、`OPTS`、`CARDS`、`STEPS`）。
- 实机版面：`vlib/footage.py` 的 `AppFootage`；每个片段的镜头/字幕在 `vlib/shots.py`
  （`APP_A`…`APP_D` 的 `keys` / `caps` / `focus`）。`keys` 是 `(本版秒数, 缩放, 中心x, 中心y)`，
  `focus` 是源坐标的高亮框，`caps` 是 `(本版秒数, 主字幕, 副字幕)`。
- 剪辑与时长：`vlib/shots.py` 的 `SHOTS` 与 `DUR`；`check()` 强制断言切点落在拍上、首尾相接、
  源片段不长于版面。
- 调色板 / 字体 / 后处理：`vlib/core.py`（`HEX` 表、`finish()` 里的 bloom、色调肩、颗粒、暗角）。
- 音乐窗口：`prep_audio.py` 顶部的 `CLIP_START` / `CLIP_LEN`，改完重跑一遍就能拿到新的拍网格。

## 渲染

```bash
# 1) 分析音乐，产 work/audio.json（拍网格 + 60fps 特征）
.venv/Scripts/python.exe docs/video/prep_audio.py

# 2) 抽几帧看构图（先用 stills 判断，再花时间渲全片）
.venv/Scripts/python.exe docs/video/render.py stills --t 13.0,26.0,41.0,49.0

# 3) 联系表
.venv/Scripts/python.exe docs/video/render.py sheet --n 24 --cols 4

# 4) 全片（14 进程，52–92 秒的片子约 10–20 分钟）→ 直接出 mp4
.venv/Scripts/python.exe docs/video/render.py video --jobs 14
```

依赖：`numpy`、`Pillow`、`scipy`、`imageio-ffmpeg`（ffmpeg 7.1 随包）、PySide6（抓实机画面）、
Windows 自带字体（微软雅黑粗体做中文、Bahnschrift 做拉丁大数字、Cascadia Mono 做机器口吻的标签）。

## 几条不能破的规矩（沿用 TREATMENT.md）

1. 调色板封闭：ink / bone / signal 橙三色；橙只给"最要紧的那一下"，骨白字不发光。
2. 切点落在拍子上；版式内部用强缓动（outExpo / inOutCubic / outBack），先停住再猛地动。
3. 中英混排必须按字选字体，否则等宽字体里的中文会变豆腐块（`Layer.text_mixed`）。
4. 纸场要先反向抬高纸色再走色调肩（`inv_shoulder`），否则整张纸会发灰。
5. 颗粒用**静态**噪声场：每帧换种子会把码率顶到 270 Mbit/s，静态颗粒只有 3.8 Mbit/s。
6. 实机画面的叠层一律用 `mode="over"`：白底界面上 `add` 会直接烧成白色，橙色圈就没了。
7. 实机镜头最大 1.1 倍：再往上就是放大 1080p 截图，字会糊；推轨靠平移和缓动，不靠死推。
8. 底部字幕条不透明、固定 108 px：实机画面里一律让出这块，别把文字压在应用的表格上。
