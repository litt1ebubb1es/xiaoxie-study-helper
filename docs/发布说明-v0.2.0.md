## 小蟹学习助手 v0.2.0

Windows 10/11 桌面版，**免安装**：下载下面那个 zip，解压，双击 `小蟹学习助手.exe` 就能用。
不需要装 Python，不需要管理员权限，数据全在本机。

> 从 v0.1.0 升上来：直接把新 zip 解压到别处，再把旧文件夹里的 `data\` 目录整个拷过去，
> 课程、回看点、知识点、设置都在里面。不要覆盖安装到同一个文件夹。

### 安装（三步）

1. 下载并**解压** `xiaoxie-study-helper-v0.2.0-win64.zip` 到任意文件夹（别在压缩包里直接双击，会缺文件）；
2. 双击 `小蟹学习助手.exe`。首次运行 Windows 会弹「已保护你的电脑」→ 点**更多信息 → 仍要运行**
   （exe 没有代码签名证书，这是常态，不是病毒）；
3. 进「设置与模型部署」：选服务商 → 点「去哪拿 Key？」申请 → 粘贴 → 点「刷新列表」选模型 → 保存。

打不开或有疑虑：双击包里的 **`一键自检.bat`**，它会跑一遍完整自检（建库→分析→诊断），
结果打在黑框里，并把 `data\logs\app.log` 弹出来。自检过了说明程序本身没问题。

### 这一版做了什么

**左栏：一次只看一个收藏夹**

以前左栏把**所有课的节**平铺在 248px 的一栏里，课一多就挤成一团，而且分不清哪一行属于哪门课。
现在：

- 左栏顶部是**收藏夹下拉**，下面列表只列当前这门课的节；
- 选中项记在 `data/ui_state.json` 的 `side_course`，下次打开还是它；
- 从 B 站导入完成后**自动切到刚导入的那门**——不切过去的话你还看着上一门，容易以为导入失败了；
- 课程名常常很长（「概率论与数理统计（4 小时速成）」），下拉会截断，鼠标悬停看完整名字。

**不再显示「第 N 节」**

节号是软件自己按导入顺序数出来的，跟用户心里的课程顺序对不上（从 B 站导入的课，
标题里本来就写着「第 74 集」，旁边再挂一个软件编的「第 1 节」，只会让人困惑）。现在：

- 左栏列表只显示**节标题 + 时长**；
- 顺序按**导入先后**（`ORDER BY rowid`）。这里有个坑值得记：第一版改按 `created_at` 排，
  结果一批导入的节经常撞在同一毫秒上，排序退化成按节号，顺序看着更像随机的；
- 知识点详情、诊断报告、小测的回看点下拉里提到「哪一节」时，也改用节标题而不是节号。

**侧栏版本号**

显示 `v0.2.0 · 本地运行`。原来写的是「端侧」——这个词是技术方案里的说法，用户看不懂，
而且这本来就是本地运行的软件。版本号改成从 `dsh_app/__init__.py` 读，不再两处手写。

### 已知限制

- 只验证了 **Windows 10/11 x64**；没有 macOS / Linux 包。
- 没有代码签名证书，SmartScreen 提示无法消除；部分企业电脑策略可能直接禁止运行未签名 exe，
  那种情况只能走源码路线（`首次安装.bat`）。
- 这个包是**精简版**：不含本地离线转写栈（faster-whisper / ctranslate2 / onnxruntime，约 180 MB），
  云端 API 与同名侧车字幕照常可用。要全功能自己打：`build_win.py --full`。
- 转写/视觉都依赖你自己配的模型服务，软件本身不带任何 Key。
- 网页演示站是我这边的一台小服务器，只有 1.6 Mbps 上行；它只是给人看效果用的，
  和桌面软件的功能没有绑定关系，随时可能下线。
