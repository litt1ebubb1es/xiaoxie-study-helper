# 怎么在别人的电脑上运行

分两种情况，先看对方会不会折腾，再选：

| 场景 | 用哪种 | 对方需要装什么 |
|---|---|---|
| 把成品发给朋友/同事，点开就能用 | **[方案 A：免安装包](#方案-a免安装包推荐)** | 什么都不用装 |
| 要在对方机器上改代码、或者要用「本地离线转写」 | **[方案 B：源码 + 一次安装](#方案-b源码--一次安装)** | Python 3.10+ |
| 自己这台机器（当前状态） | 已经装好了，双击 `启动助手.bat` | — |

两个方案都是「本地运行」：界面、录音、数据库全在对方电脑上，只有调用大模型时才联网。

---

## 方案 A：免安装包（推荐）

### 打包（在你机器上做一次）

```bat
.venv\Scripts\python.exe tools\build_win.py
```

产物：

```
dist\小蟹学习助手\               ← 文件夹版，336 MB（精简版）
dist\小蟹学习助手-v0.1.0-win64.zip   ← 发这一个文件给别人
```

`--full` 会把「本地离线转写」那一套（faster-whisper / ctranslate2 / onnxruntime）
也打进去，体积 +180 MB 左右；默认精简版不含它，云端 API 和侧车字幕路线照常可用。

### 对方怎么用

1. 收到 zip → **解压到任意文件夹**（别在压缩包里直接双击，会缺文件）；
2. 双击 `小蟹学习助手.exe`；
3. 第一次会弹 Windows SmartScreen「已保护你的电脑」→ 点**更多信息 → 仍要运行**
   （exe 没买代码签名证书，这是常态，不是病毒）；
4. 打开后进「设置与模型部署」，选服务商 → 点「去哪拿 Key？」申请 → 粘贴 →
   点「刷新列表」→ 选模型 → 保存。不知道选哪家就点设置页里的
   **「怎么导入模型？（图文说明）」**。

**不用装 Python，不用装 VC 运行库，不需要管理员权限。**

### 包里有什么、要不要"一键装依赖"

解压后是这 5 样，**没有任何需要安装的东西**：

```
小蟹学习助手.exe      双击就是全部动作
_internal\            依赖全在这儿（Python 解释器、Qt、ffmpeg、音频库…
                      约 330 MB，别删、别单独挪动 exe）
一键自检.bat          不开界面跑一遍核心链路，结果打在黑框里 + 弹 data 文件夹
使用说明.txt          用户视角的上手与排错
README.md / LICENSE   项目说明与许可
data\                 空的，运行时长出来的就是你的数据
```

> **免安装包不需要"装依赖"这一步**：依赖已经被 PyInstaller 打进 `_internal\` 了。
> 想让对方"一键验证没装坏"，用 `一键自检.bat`；真需要装依赖的是
> [方案 B](#方案-b源码--一次安装)，那儿有 `首次安装.bat`。

`一键自检.bat` 实际输出（在解压出来的副本、清空环境变量下实测）：

```
  小蟹学习助手 - 一键自检（不开界面，约 10 秒）
正在检查：数据库 / 分析 / 回看点 / 诊断 / 生成讲解 ...
session=sess_1bf3e3719ca7
windows=30 knots=2
diagnosis: knots=2 plan=1 related=0 root_causes=0
[OK] 自检通过，程序本身没问题。
     如果界面里某功能不好用，多半是 API Key、网络或录音设备的问题。
现在打开 data 文件夹，日志在 logs\app.log
```

**运行库**：`_internal\VCRUNTIME140.dll` 与 `_internal\PySide6\MSVCP140.dll` 都已随包自带，
干净系统也能起。万一系统提示缺 `MSVCP140.dll`（通常是杀软孤立删了 PySide6 里的文件，
或用了 32 位系统），装一次「Microsoft Visual C++ 2015-2022 运行库 x64」即可。

### 数据在哪、怎么升级

- 数据在程序旁边的 `data\`：`config.json`（含 API Key，只在本机）、`app.db`（课程/知识点）、
  `audio\`（录音）、`logs\`（出问题发这个）。
- 整个文件夹拷走 = 连数据一起搬走。
- **升级**：把新的 `小蟹学习助手.exe` 和 `_internal\` 覆盖进旧文件夹，
  `data\` 不要动，数据自动沿用（数据库有版本迁移，旧库能直接打开）。
- **卸载**：删文件夹就完事，不写注册表（除了一个快捷方式都没有）。
- 如果对方把文件夹丢进 `C:\Program Files` 之类不可写的位置，数据会自动改存
  `%LOCALAPPDATA%\小蟹学习助手\data`——`--selftest` 和日志里都能看到实际路径。

## 方案 B：源码 + 一次安装

适合：要改代码、要用本地离线转写、或者对方本来就装了 Python。

1. 把整个项目文件夹拷过去（`.venv\`、`data\`、`_ref\`、`dist\` 可以不拷）；
2. 双击 **`首次安装.bat`**：找 Python → 建 `.venv` → 装依赖（先走阿里云镜像，
   不行再走官方源）→ 生成带螃蟹图标的启动器 → 跑一遍自检；
3. 装完双击 `启动助手.bat` 使用。

> 对方没 Python 的话，`首次安装.bat` 会直接说明去 python.org 下 3.11/3.12，
> 并提醒勾上「Add python.exe to PATH」。

手动等价命令（出问题时照这个排）：

```bat
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -U pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe tools_patch_exe_icon.py
.venv\Scripts\python.exe run_app.py --selftest
```

### 为什么有 `启动助手.bat` 这个奇怪的东西

Windows 11 的任务栏图标取自**进程 exe 的资源**，Qt 的 `setWindowIcon` 只管标题栏。
所以要拿一份 `python.exe` 的副本、把螃蟹图标焊进它的 PE 资源（`tools_patch_exe_icon.py`），
再用它跑 `run_app.py`。方案 A 的 exe 本来就是我们自己的 exe，不存在这个问题。

## 自检与排错

任何机器上都能跑（不开界面）：

```bat
小蟹学习助手.exe --selftest          :: 方案 A
.venv\Scripts\python.exe run_app.py --selftest   :: 方案 B
```

会建库 → 造演示会话 → 分析 → 打印窗口/回看点/诊断结果，退出码 0 表示核心链路正常。
打包版会把输出同时写进 `data\logs\app.log`（windowed exe 没有控制台，靠这个看）。

常见问题：

| 现象 | 原因 / 处理 |
|---|---|
| 双击没反应 | 看 `data\logs\app.log` 末尾；多半是缺文件（压缩包里直接运行）或杀软拦了 |
| SmartScreen 拦住 | 更多信息 → 仍要运行；企业电脑策略不许运行未签名 exe 时，只能走方案 B |
| 设置页「刷新列表」报错 | 先看是不是 Key 错（401）——见 [算法说明.md 缺口 28](算法说明.md) 里的另一类坑（`process()` 报错是环境问题，已修） |
| 录音设备为空 | Windows 设置 → 声音 → 确认有输出设备；蓝牙耳机要在播放状态才枚举得到 |
| 说话没声音但有画面 | 用的是「系统环回」录音，先把视频音量打开；静音的窗口录不到声音 |
| 本地转写选项是灰的 | 精简版没打包 faster-whisper，用方案 B 或 `build_win.py --full` |

## 打包的技术选择（为什么这么做）

- **onedir 不做 onefile**：onefile 每次启动把几百 MB 解到 `%TEMP%`，冷启动十几秒，
  杀软还会反复扫自解压行为；onedir 就是普通进程启动。代价是要发文件夹——zip 一下即可。
- **精简版默认不含本地转写栈**：那套 180 MB，而朋友机器上本来也没下模型权重；
  云端路线（百炼/DeepSeek…）和「同名侧车字幕」够用。要全功能加 `--full`。
- **数据目录跟 exe 走**：解压即用、拷贝即迁移；不可写时自动退到 `%LOCALAPPDATA%`。
- **exe 名与图标**：`docs/icon/xiaoxie.ico` 打进 exe 资源，任务栏/开始菜单一致。

## 已知限制

- 只验证了 Windows 10/11 x64；没有 macOS/Linux 的打包脚本。
- 没有代码签名证书，SmartScreen 提示无法消除（企业环境可能直接禁止运行）。
- 精简版不含本地离线转写；`--full` 版也不含 whisper 权重（首次用会自己下）。
- 打包体积 336 MB（`--full` ≈ 520 MB），zip 后仍有一两百 MB，发微信文件可能超限。
