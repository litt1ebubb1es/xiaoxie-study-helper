## 小蟹学习助手 v0.1.0

Windows 10/11 桌面版，**免安装**：下载下面那个 zip，解压，双击 `小蟹学习助手.exe` 就能用。
不需要装 Python，不需要管理员权限，数据全在本机。

### 安装（三步）

1. 下载并**解压** `xiaoxie-study-helper-v0.1.0-win64.zip` 到任意文件夹（别在压缩包里直接双击，会缺文件）；
2. 双击 `小蟹学习助手.exe`。首次运行 Windows 会弹「已保护你的电脑」→ 点**更多信息 → 仍要运行**
   （exe 没有代码签名证书，这是常态，不是病毒）；
3. 进「设置与模型部署」：选服务商 → 点「去哪拿 Key？」申请 → 粘贴 → 点「刷新列表」选模型 → 保存。

不知道选哪家、怎么开 Key：点设置页里的「怎么导入模型？（图文说明）」。

打不开或有疑虑：双击包里的 **`一键自检.bat`**，它会跑一遍完整自检（建库→分析→诊断），
结果打在黑框里，并把 `data\logs\app.log` 弹出来。自检过了说明程序本身没问题。

### 这一版做了什么

**课程身份（判"是不是同一门课"）**
- 以前标题差一个空格、全角括号、多一个「完整版」后缀，就会被当成新课程；
  现在按归一化键判同一门课（NFKC → 去标签段 → casefold → 去标点），历史数据自动回填迁移。
- 录制/导入时课程名是可编辑下拉（显示「课程名 — N 节」），第 N 节按**该课程**已有节数算。
- 明确不做的事：不猜简称、不猜繁体、不自动合并历史重复。

**模型接入（修掉一个很怪的报错）**
- 修 `模型列表失败：TypeError: process() takes no keyword arguments`。
  根因是「base 解释器 + 项目 venv」混用：venv 的 httpx2 解 `br` 压缩时调
  `process(..., output_buffer_limit=)`，而 base 的 brotli 1.1.0 是 C 实现、不认这个关键字。
  现在启动时探测一次，不认就把 `br` 从 Accept-Encoding 摘掉，改走 gzip——用户不用装东西。
- `/models` 改成自己发请求，认三种返回形态，绕开 SDK 对非标准网关的脆弱解析。
- **拉不到模型列表也不用手填**：用该服务商的预设候选自动填好下拉，状态栏说明原因。

**分发**
- 一键打包：`.venv\Scripts\python.exe tools\build_win.py`（onedir + zip + 使用说明 + 清理本机痕迹）。
- 数据目录跟 exe 走（解压即用、拷走即迁）；目录不可写时自动退到 `%LOCALAPPDATA%\小蟹学习助手\data`。
- windowed exe 没有控制台，输出 tee 到 `data\logs\app.log`，报 bug 发这个文件即可。
- 包里带 `一键自检.bat`；源码路线另有一键装依赖的 `首次安装.bat`。

详细说明：[docs/安装与分发.md](https://github.com/litt1ebubb1es/xiaoxie-study-helper/blob/main/docs/安装与分发.md)

### 已知限制

- 只验证了 **Windows 10/11 x64**；没有 macOS / Linux 包。
- 没有代码签名证书，SmartScreen 提示无法消除；部分企业电脑策略可能直接禁止运行未签名 exe，
  那种情况只能走源码路线（`首次安装.bat`）。
- 这个包是**精简版**：不含本地离线转写栈（faster-whisper / ctranslate2 / onnxruntime，约 180 MB），
  云端 API 与同名侧车字幕照常可用。要全功能自己打：`build_win.py --full`。
- 转写/视觉都依赖你自己配的模型服务，软件本身不带任何 Key。
